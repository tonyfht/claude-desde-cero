# Soluciones · la app «Mis tareas» fase a fase

| Carpeta | Estado de la app |
|---|---|
| `fase-06/` | App creada con Claude Code y su `CLAUDE.md` |
| `fase-07/` | Con filtros Todas / Pendientes / Hechas |
| `fase-08/` | Con permisos en `.claude/settings.json` y `.gitignore` |
| `fase-09/` | Con servidor MCP, hook, subagente, skill y `NOVEDADES.md` |
| `fase-10/` | Con fecha límite y tareas vencidas, especificada con OpenSpec |

Para usar una como punto de partida, copia su contenido a una carpeta nueva, ejecuta `git init` y abre `claude`.
En la fase 8 necesitarás crear tu propio `.env` de prueba (no se incluye a propósito).
