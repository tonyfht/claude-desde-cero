# CLAUDE.md · mis-tareas

App web de lista de tareas hecha con HTML, CSS y JavaScript, sin dependencias ni paso de compilación.

## Cómo se ejecuta
- Abrir `index.html` en el navegador. No hay servidor ni build.

## Reglas del proyecto
- Todo el código vive en `index.html` (HTML, `<style>` y `<script>`), salvo que se pida separarlo.
- Sin librerías externas ni CDN.
- Los datos se guardan en `localStorage` con la clave `mis-tareas`.
- Textos de la interfaz en español.
- Accesibilidad: cada control con su etiqueta, se puede usar con teclado y el contraste cumple AA.

## Forma de trabajar
- Antes de cambios grandes, propone un plan y espera a que lo apruebe.
- Commits en español y en imperativo: «Añade filtro de tareas pendientes».
